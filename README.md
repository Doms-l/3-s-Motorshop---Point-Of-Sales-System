# 3’S Motorshop POS System

A desktop-based Point of Sale (POS) and Inventory Management System designed for 3’S Motorshop. This application helps manage sales transactions, products, customers, inventory, and other essential motorshop operations through a simple and user-friendly interface.

## 📌 Project Overview

The **3’S Motorshop POS System** is developed to make daily motorshop operations faster, easier, and more organized. It provides tools for handling sales, monitoring inventory, managing customer information, and tracking business transactions.

The system features a modern desktop interface with a red-and-black theme.

## ✨ Features

### 1. Point of Sale (POS)
- Process customer purchases.
- Automatically calculate subtotals and total amounts.
- Manage items in the sales transaction.
- Search products using barcode or product information.
- Generate sales receipts.

### 2. Inventory Management
- Add, edit, and manage products.
- Monitor available product stocks.
- Track product information and pricing.
- Help prevent stock shortages.

### 3. Customer Management
- Register and manage customer information.
- View customer records.
- Maintain customer purchase history.

### 4. Customer Loyalty and Rewards
- Manage customer loyalty records.
- Provide rewards for eligible customers.
- Encourage repeat purchases.

### 5. Returns and Warranty Management
- Record returned products.
- Manage warranty information.
- Track product return transactions.

### 6. Product Reservations
- Reserve products for customers.
- Manage reservation records.
- Monitor reserved product availability.

### 7. Sales Management
- Record sales transactions.
- View transaction records.
- Monitor daily sales activities.

## 🚀 Installation and Usage

### Option 1: Using the Installer

1. Download the 3’S Motorshop POS installer.
2. Run the installer.
3. Follow the installation instructions.
4. Open the application from your desktop shortcut or Start Menu.
5. Log in using your account credentials.

### Option 2: Running Through NetBeans

1. Download or clone this repository.
2. Open NetBeans IDE.
3. Select **File → Open Project**.
4. Locate the downloaded project folder.
5. Open the project.
6. Configure the required database connection.
7. Run the project.
